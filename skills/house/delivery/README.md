# Delivery

House skills for shipping a piece of work end to end — the implementation pipeline and the output conventions it writes with. Fork-authored: upstream owns none of these bytes.

## Beta

- **[project-organization](./project-organization/SKILL.md)** — single source of truth for file locations, naming conventions, and markdown templates; other skills invoke it to resolve any output path.
